# Pilot Launch Plan

The pilot goal is to convert design partners into paying customers by proving that AegisWeb safely automates real vendor workflows.

## Design Partner Criteria

Select 3-5 partners with:

- SaaS-heavy operations with 10+ vendor portals.
- Existing approval workflow pain.
- A named security or operations owner.
- Willingness to provide weekly feedback.
- Permission to run at least one real or production-like workflow.

## Onboarding Sequence

1. Confirm partner owner, approvers, and pilot workflows.
2. Create workspace and invite users.
3. Enable MFA for owner/admin/approver roles.
4. Add first vendor and vault credential.
5. Configure policy bundle.
6. Run the first workflow together.
7. Review receipt and audit trail.
8. Schedule weekly check-in.

## Success Metrics

- Workflow success rate above 95%.
- Approval response time under 30 minutes.
- Credential vault: zero leaks.
- Receipt trust: zero integrity failures.
- NPS above 40.

## Feedback Loop

- Weekly check-in calls.
- In-app feedback collection.
- Usage analytics only with explicit partner opt-in.
- Feature requests tracked with partner, severity, workflow, and revenue impact.

## Conversion Criteria

A partner is ready to convert when:

- At least one recurring workflow runs successfully.
- Security owner accepts the control model.
- Operations owner sees time saved or risk reduced.
- Pricing owner confirms buying path and billing contact.
