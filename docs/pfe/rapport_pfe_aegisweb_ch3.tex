\chapter{Conception du système}

\begin{chapintro}
Ce chapitre décrit la conception architecturale et la modélisation du
système AegisWeb. Nous y présentons l'architecture monorepo, les
modélisations dynamiques et statiques, ainsi que le dictionnaire de
données Prisma.
\end{chapintro}

\section{Architecture générale du système}

\subsection{Architecture logicielle — Monorepo}

AegisWeb repose sur une \textbf{architecture monorepo TypeScript} (pnpm
workspaces) avec séparation claire entre applications et bibliothèques
partagées.

\begin{figure}[H]
\centering
\diagramespace[6.5cm]{Schéma d'architecture AegisWeb — Utilisateur/Approver
  $\rightarrow$ Next.js Web (3000) $\rightarrow$ NestJS API (3001)
  $\rightarrow$ PostgreSQL + Redis/BullMQ + MinIO/S3 — Worker
  $\rightarrow$ Playwright $\rightarrow$ Vendor Sandbox (4202)}
\caption{Architecture logicielle globale d'AegisWeb}
\label{fig:archi_global}
\end{figure}

\conclusionchap{La conception d'AegisWeb révèle une architecture modulaire
et sécurisée~: monorepo TypeScript, séparation control plane / worker,
moteur de politiques pur, vault chiffré et modèle de données Prisma riche
en 17 tables. Ces fondements guident notre implémentation, décrite dans
le chapitre suivant.}
